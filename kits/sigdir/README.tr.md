# SIĞDIR + CSDurağı eksen modülü

**CS 1.6 MOTD kiti · ücretsiz**

![SIĞDIR + CSDurağı eksen modülü](img/sigdir-1.jpg)

Web MOTD sayfalarına SIĞDIR butonu ve ayar paneli ekler; bizim ek modülümüz CSDurağı istemcisine de yatay ve dikey ince ayar getirir.

`PHP 5.4+` · `Steam MOTD` · `CSDurağı` · `Çerez`

## Özellikler

**Steam MOTD ve tarayıcılar**  
Otomatik sığdır, ayrı yatay/dikey ölçek ve zoom, sürükleyerek boyutlandırma; ayarlar çerezde hatırlanır.

**CSDurağı (Trident/IE7)**  
sigdir-eksen.php boyutları sunucuda gerçek CSS olarak üretir: transform/zoom yok, tıklama noktası kaymaz. JavaScript olmadan da çalışır; aralık %50–120.

**Gereksinimler**  
PHP 5.4 veya üstü. Veritabanı, şifre ya da dış kütüphane yok; sadece çerez, dışarıya istek yok. README.md ve demo.php pakette.
